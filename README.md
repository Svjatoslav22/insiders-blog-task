# insidersBlog

Тестове завдання: Міні-блог на Next.js та Express.

## 🛠 Стек
- **Frontend:** Next.js (App Router), TypeScript, Tailwind CSS
- **Backend:** Express, TypeScript, Prisma ORM
- **База даних:** PostgreSQL
- **Авторизація:** JWT, bcrypt

## ⚡ Швидкий старт

### Бекенд:
```bash
cd backend
npm install
npx prisma migrate dev
npx prisma db seed
npm run dev
```
Сервер запуститься на `http://localhost:4000`.

### Фронтенд:
```bash
cd frontend
npm install
npm run dev
```
Додаток буде доступний на `http://localhost:3000`.
